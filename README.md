# Y700 统一温控增强 + 充电日志 及配套监控 App

联想拯救者 Y700 平板（三代/四代/五代）的 **Magisk / KernelSU 温控增强模块**，以及**配套的实时充电监控 App**。

| 组成 | 说明 |
|------|------|
| **模块** (`module/`) | 温控绕过 + 亮屏快充增强 + 充电日志 |
| **App** (`app/`) | 实时充电可视化 + 每次充电自动存档（数据独立于模块日志） |

## 支持机型

| 型号 | 代际 | 状态 |
|------|------|------|
| TB321FU | 三代 | ✅ 已验证 40W+ 快充 |
| TB322FC | 四代 | ✅ 兼容 |
| TB323FU | 五代 | ✅ 已验证 40W+ 快充 |

## 一、模块

### 功能

1. **温控绕过**：禁用充电相关温区 + 伪装温度，消除充电/游戏时的降频限流
2. **亮屏快充增强**：插电时伪装温度 + 维持温区禁用，实现亮屏高功率充电；拔线后清除伪装、温控保持关闭
3. **充电日志**：记录每次充电的**电池功率**/温度/分阶段统计/**充电协议**/**输入电压**，保存到 `/sdcard/充电日志/`
4. **多代适配**：温区按类型自适应扫描，兼容三代 `batt1-therm`/四五代 `batt-pack-therm` 等命名差异
5. **单实例守护**：开机时 KSU 与 service.d 同时拉起也不重复执行

> **关于「输入功率」**：SDP / DCP（普通充电）下正常显示；**PD / PPS 快充时平台不向用户空间暴露输入电流**
> （大电流走电荷泵，已实测确认），此时日志显示「**不可读**」并给出 **PPS 输入电压峰值**。
> 快充时请以**电池功率**为准（实测可达 **51W+**）。

### 安装

1. 从 **[Releases](https://github.com/aweiyry/y700_thermal_boost/releases)** 下载 `y700_thermal_boost_vX.X.zip`（或用 `module/` 目录自行打包）
2. 通过 Magisk 或 KernelSU 刷入
3. 重启

### 配置

修改 `/data/adb/modules/y700_thermal_boost/config.prop`（改后重启生效）：

```
ENABLE_THERMAL_BYPASS=1   # 温控绕过 (1=开 0=关)
ENABLE_CHARGE_LOG=1       # 充电日志 (1=开 0=关)
SAMPLE_INTERVAL=5         # 采样间隔(秒)
FAKE_TEMP_CHG=25000       # 充电区伪装温度 (毫摄氏度, 25000=25C)
FAKE_TEMP_BATT=28000      # 电池区伪装温度
FAKE_TEMP_USB=25000       # USB区伪装温度
FAKE_TEMP_AP=30000        # AP区伪装温度
LOG_KEEP_COUNT=30         # 日志保留数量
KILL_INTERVAL=60          # 杀温控进程间隔(秒)
```

## 二、配套 App（Y700 充电监控）

用 [libsu](https://github.com/topjohnwu/libsu) 直读 `/sys` 节点，Kotlin + Jetpack Compose 实现。

### 功能

- **实时可视化**：环形电量仪表 + 功率/电量/温度三张实时曲线（每秒刷新，每 2 秒落点）
- **实时指标**：充电协议（PD/PPS/DCP/SDP…）、电池功率、输入电压/电流/功率、温度、电流、电压、CCL、输入电流上限、充电阶段
- **每次充电自动存档**：自动识别充电开始/结束，全程记录采样点（功率/输入功率/电量/温度/电流/电压）
- **历史记录**：列表（充入电量、时长、峰值功率、协议、能量）+ 详情页（完整统计 + 该次曲线），支持单条删除/清空
- **模块状态**：显示模块版本与运行状态（`/proc` 校验，不依赖 `ps`）
- **输入不可读时如实标注**：PPS 快充下输入电流不可得，显示「不可读」而非骗人的 0

### 数据独立性

App 数据保存在 **App 私有目录**（`/data/data/com.y700.charge/files/`），仅读取 `/sys` 节点，
**不读取也不写入模块的 `/sdcard/充电日志/`**，两者完全独立。

### 构建

```bash
cd app
./gradlew assembleDebug
# 产物: app/build/outputs/apk/debug/app-debug.apk
```

### 使用

1. 从 **[Releases](https://github.com/aweiyry/y700_thermal_boost/releases)** 下载 `y700_charge_monitor_vX.X.apk` 并安装
2. 打开 App，首次会弹 KernelSU/Magisk root 授权，点「允许」
3. 即可看到实时充电信息，右上角「历史记录」查看每次充电存档

## 故障诊断（模块没生效时用）

社区反馈「模块没生效」时，让用户跑诊断脚本 `tools/y700_diag.sh` —— 自动检测所有作用点并生成报告：

```bash
# 在平板终端 App 中执行（需 root）
su -c "sh /data/local/tmp/y700_diag.sh"
# 可选参数: 采样时长(秒), 默认 60
su -c "sh /data/local/tmp/y700_diag.sh 120"
```

脚本运行约 1 分钟后自动生成报告到 **`/sdcard/Y700模块诊断_<时间>.txt`**，包含：

| 检查项 | 说明 |
|---|---|
| 环境信息 | 机型 / Android / 内核 / root / SELinux 上下文 |
| 模块安装 | 模块目录 / 版本 / `disable` 标志 / service.d 自启脚本 |
| 服务进程 | 是否运行（直查 `/proc`，不依赖 `ps`）、是否多实例 |
| **温区检查** | 设备**全部温区类型**列表 + 目标温区 `mode`/`temp` 与期望伪装值逐项对比 |
| 写入权限 | `emul_temp` / `mode` 是否可写（SELinux 拦截会直接暴露） |
| 温控进程 | thermal-engine / thermal HAL 状态 |
| 充电与节点 | 充电协议 / 输入电压电流 / CCL / 输入电流上限 / **充电限流冷却设备状态** / IIO 输入电流节点 |
| **动态采样** | 每分钟 12 次采样，检测温度伪装是否**稳定维持**（抓「有时有效有时无效」） |
| 自动结论 | 直接列出发现的问题与建议 |

把生成的报告文件发出来即可定位问题（报告只含系统状态，不含隐私信息）。

## 版本历史

### 模块

- **V6.7** — 杀温控进程改为**按进程名通用匹配**（兼容 `android.hardware.thermal-service@1.0` 等非 `.qti` 命名，提升异机型兼容性）；诊断脚本增强：**CCL 可写性测试** + **电池温度/输入功率/充电限流分析**
- **V6.6** — 修复开机多实例竞态（原锁文件方案在「创建后内容未写入」时被误判为残留锁，导致两个实例同时运行、日志互相覆盖）；诊断脚本新增「充电限流冷却设备」检查
- **V6.5** — 输入电流改用 PMIC IIO ADC 节点；PPS 下输入功率不可读时如实标注 + 记录 PPS 电压峰值；新增诊断脚本
- **V6.4** — 充电日志增加「输入功率」统计；修复充电协议在最终日志恒为「未识别」
- **V6.3** — 充电日志增加「充电协议」行（PD/PPS/DCP/SCP 等）
- **V6.2** — 修复单实例锁 pid 复用导致的偶发失效（有时有效有时无效）
- **V6.1** — 三代 CCL 写入修复（单位不同导致限流 + PPS 反复重协商）
- **V6.0** — 三代温区适配 + 机型识别 + 单实例锁原子创建
- **V5.9** — 温区发现按类型自适应扫描
- **V5.8** — 单实例锁（初版）
- **V5.7** — 拔线清除伪装 + 杀进程限频 + 写回验证

### App

- **v1.3** — 同步输入电流 IIO 节点修复；不可读时明确标注；「充电类型」改名「充电阶段」
- **v1.2** — 修复模块状态误判为「未运行」（`ps` 不显示完整命令行，改用 `/proc` cmdline 校验）
- **v1.1** — 实时图表可视化 + 充电会话自动记录 + 历史列表/详情
- **v1.0** — 首个版本：libsu 直读 `/sys` 实时充电信息

## 项目结构

```
.
├── module/                 # Magisk/KernelSU 模块源码
│   ├── service.sh          # 核心逻辑 (温控绕过/伪装/充电日志)
│   ├── customize.sh        # 安装脚本 (生成 service.d 开机脚本)
│   ├── uninstall.sh        # 卸载时恢复温区

│   └── module.prop         # 模块信息
├── tools/
│   └── y700_diag.sh        # 一键诊断脚本 (社区排障用, 检测9个作用点)
├── promo/                  # 宣传海报与生成脚本
│   ├── poster_v6.4.png
│   └── make_poster.ps1
└── app/                    # 配套 Android App
    ├── app/src/main/java/com/y700/charge/
    │   ├── MainActivity.kt         # 导航
    │   ├── data/ChargeReader.kt    # libsu 读取 /sys
    │   ├── data/ChargeRepo.kt      # 轮询 + 会话记录
    │   ├── data/Models.kt          # 数据模型 + JSON
    │   ├── data/SessionStore.kt    # 会话持久化
    │   └── ui/                     # Compose 界面与图表
    └── README.md
```
